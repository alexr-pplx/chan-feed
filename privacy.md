# Chan feed — Privacy Policy

Last updated: September 30, 2026

Chan feed is a private Discord bot run on one server only, the Perplexity community Discord. It can't be added to any other server.

## What it does

- Assigns community roles automatically, following the server's FAQ.
- Collects the feedback and bug reports members post for review.
- Reposts announcements to Perplexity's other community channels.
- Enforces the posting requirements set in channel descriptions.

## What data it uses

- Your Discord user ID, username, nickname, roles and server join date.
- The posts it works with: their text, attachment links and time posted.

It doesn't read direct messages.

## How it's shared

- LLM APIs might be used to sort reports.
- If you tag a report as API-related, it might be shared on the Perplexity community forum for the team to fix, with your Discord username.

The bot's data isn't sold or used to train any AI model.

## How long it's kept

As long as it's needed to run the bot, or until you ask for it to be deleted.

## Your data, on request

Email alexr@perplexity.ai with your Discord username to see what's stored about you or have it deleted. You may be asked to confirm the request from that Discord account. Requests are handled within 30 days.
